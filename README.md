# breakin-shit

A simple Three.js 3D visualization project.

## Features

- Interactive 3D scene with rotating geometric shapes
- Three different 3D objects: cube, sphere, and torus
- Animated particle system with 1000 floating particles
- Dynamic lighting with multiple point lights
- Orbit controls for camera manipulation (drag to rotate view)
- Responsive design that adapts to window resize

## How to Use

Simply open `index.html` in your web browser. No build process or dependencies required!

The visualization includes:
- A rotating green cube
- A red sphere that bounces up and down
- A cyan torus with rotation animation
- Floating particle stars in the background
- Interactive camera controls (click and drag to orbit)

## Technology

- Three.js r128 (loaded via CDN)
- Pure HTML/CSS/JavaScript
- No build tools required
