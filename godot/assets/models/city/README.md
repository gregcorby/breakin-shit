# City Building Models

## Current Status
Currently using procedural buildings with windows (see `scripts/ProceduralAssets.gd`)

## Download Real 3D Models

**Recommended Source:** Kenney City Kits
- Commercial Kit: https://kenney.nl/assets/city-kit-commercial
- Suburban Kit: https://kenney.nl/assets/city-kit-suburban
- Roads Kit: https://kenney.nl/assets/city-kit-roads
- License: CC0 (Public Domain)
- Attribution: Kenney (kenney.nl)

**What's Included:**
- 50+ building models in Commercial kit
- Multiple formats: FBX, OBJ, GLTF
- Pre-textured and ready to use
- Optimized for games

**Alternative Source:**
- Poly Pizza bundle: https://poly.pizza/bundle/City-Kit-0CkvGrBJ0u

## Integration Instructions

1. Download the ZIP file from Kenney
2. Extract to this directory
3. Update `scripts/CityGenerator.gd`:
   - Replace procedural building generation with model loading
   - See `ASSET_GUIDE.md` for code examples
4. Re-export and test
